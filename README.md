# Teaching Python for the New Era

A beginner Python course taught live by Ashutosh, built for the AI era: you write every line yourself, predict before you run, and learn on data from your own real work. No installing anything, every lesson is a Google Colab notebook you can open, run, break, and rerun.

Built for Vineet, a healthcare professional learning Python from zero for his weekly spreadsheet and report work. The examples grow from his world: patient records, visit counts, and the repeat reports he runs every week.

## How each lesson works

1. Predict before you run. Say what the code will print, then run it and check.
2. Type the examples yourself at least once. Copy paste teaches nothing.
3. Do the challenges before the next lesson. The struggle is where the skill forms.
4. Bring your real work. From Lesson 2 onward, the practice is built from the student's own repeat spreadsheet and report tasks.

## Course map

1. Foundations (Lesson 1)
2. Functions (Lesson 2)
3. Functions on spreadsheet style tables
4. Reading real spreadsheet files
5. Cleaning and counting real report data
6. Automating a full weekly report
7. Charts and summaries
8. Capstone: the student's own report, automated end to end
